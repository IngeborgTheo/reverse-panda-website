PRIVACY

PRIVACY,
WITHOUT THE
MYSTERY.

ReversePanda is built to keep as much as possible on your device. When data does leave your phone, you should know what it is and why.

Last updated: September 2026

THE SHORT VERSION

Stays on your device

  • Installed apps
  • App searches
  • Wallpapers
  • Folder names and labels
  • Local backups
  • Launcher settings
  • Local app-usage information used by launcher features

Only shared when needed or enabled

  • Optional Analytics
  • Optional Crash Reports
  • Feedback you submit
  • Optional bug-report screenshots
  • Technical app/device information needed for those services

WHAT STAYS WITH YOU.

ReversePanda processes data locally so it can work as a launcher. That information is used on your device to show your apps, remember your layout and power features you turn on. It is not sent to ReversePanda for advertising or profiling.

  • Installed apps
  • App names and icons
  • App usage information used for local launcher features
  • Searches
  • Layouts
  • Dock configuration
  • Folders
  • Wallpapers
  • Settings
  • Local backups
  • Gestures and shortcut assignments

NO ACCOUNT REQUIRED.

ReversePanda currently has no login, user account or launcher profile. You can use the app without creating an identity with ReversePanda.

Analytics & crash reports

Anonymous Analytics

Optional product analytics run through Firebase Analytics. They are disabled by default and only turn on after an explicit opt-in.

  • No custom user ID
  • Not used for advertising
  • Only controlled product events and technical information
  • No installed-app list
  • No searches, wallpaper data or folder names
  • No feedback text or screenshots

Crash Reports

Optional crash reporting runs through Firebase Crashlytics. It is disabled by default and uses a separate opt-in from analytics.

  • Technical crash information only
  • App version, build, Android version, device model, stack trace
  • No custom user ID
  • No intentional personal launcher content

WHEN YOU CONTACT ME.

Feedback is always user initiated. You choose when to send something — ReversePanda does not submit messages in the background.

  • Send feedback — a general note, question or hello
  • Report a bug — something that broke or behaved oddly
  • Request a feature — an idea for what should exist next

Bug reports may include technical information such as ReversePanda version, build number, Android version and device model, so the issue can be understood. They do not automatically include installed apps, searches, wallpapers or folder names.

SCREENSHOTS ARE OPTIONAL.

Screenshots are never captured automatically. If you attach one to a bug report, only the image you select is uploaded.

  • Maximum one image
  • Maximum 5 MB
  • Temporarily stored in Firebase Cloud Storage
  • Privately processed
  • Attached to the bug-report email
  • Deleted after processing
  • Temporary leftovers are automatically cleaned after roughly 24 hours
  • No public download URL is created

A screenshot may contain personal information visible in the image, so review it before attaching it.

SERVICES REVERSEPANDA USES

Google Firebase

Used for

  • Analytics
  • Crashlytics
  • App Check
  • Cloud Functions
  • Cloud Storage

Resend

Used for

  • Delivering feedback, bug-report and feature-request emails

SECURITY WITHOUT ACCOUNTS.

ReversePanda does not currently require an account. Backend requests are protected with Firebase App Check. Production builds use Play Integrity, with backend validation and restricted Storage rules. Secrets are not stored in the Android app.

YOU DECIDE WHAT'S OPTIONAL.

  • Anonymous Analytics Off by default
  • Crash Reports Off by default
  • Feedback Sent only when submitted
  • Screenshots Uploaded only when selected

Analytics and Crash Reports can be enabled or disabled independently in the app.

DATA STORAGE

ReversePanda does not keep a dedicated feedback database. Feedback is validated and forwarded by email. Temporary screenshots are deleted after processing. Local backups remain on your device, or wherever you explicitly export them.

CHILDREN

ReversePanda is a general-purpose Android launcher and is not directed at children. It does not knowingly collect personal information from children for marketing or profiling. If you believe a child has submitted personal information through feedback, contact the address below so it can be reviewed and removed where possible.

POLICY CHANGES

This policy may change as ReversePanda grows. When it does, the “Last updated” date at the top of this page will change. Significant updates that affect how optional data is handled will be reflected in the app’s privacy settings where relevant.
